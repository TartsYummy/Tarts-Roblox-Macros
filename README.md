# Roblox Macro Collection

A collection of macros made for Roblox using mostly AutoHotkey.

## Features
- Fishing macros
- Auto clicking / movement macros
- PixelSearch based automation

## Requirements
- AutoHotkey v2

## Usage
1. Install AutoHotkey v2
2. Download the macro
3. Run the `.ahk` file
4. Follow the hotkey instructions inside the script
