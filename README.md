# Roblox Macro Collection

A collection of macros made for Roblox using AutoHotkey.

## Features
- Fishing macros
- BedWars utility macros
- Auto clicking / movement macros
- PixelSearch based automation

## Requirements
- AutoHotkey v2
- 1920x1080 resolution recommended
- Roblox in windowed or fullscreen mode

## Usage
1. Install AutoHotkey v2
2. Download the macro
3. Run the `.ahk` file
4. Follow the hotkey instructions inside the script
